# HealthBridge Disease Prediction System

## Project Objective
Build an AI/ML-based symptom checker that predicts possible diseases from user-entered symptoms.

## System Architecture

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Machine Learning Model Training
5. Model Evaluation
6. SHAP Explainability
7. FastAPI Backend
8. Streamlit Frontend

## Planned Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- Streamlit
- SHAP

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
