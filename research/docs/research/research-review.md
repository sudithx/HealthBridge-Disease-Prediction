# Research Review – HealthBridge Disease Prediction

## 1. Optimizing Classification of Diseases Through Language Model Analysis of Symptoms

**Research source:** https://pmc.ncbi.nlm.nih.gov/articles/PMC10794698/

**Summary:**
This research explores disease prediction using symptom descriptions. It evaluates MCN-BERT and BiLSTM models to classify diseases from symptom-related text.

**What I learned:**
- Symptoms can be converted into machine-readable data.
- Deep learning can identify relationships between symptoms and diseases.
- Model performance should be evaluated using multiple metrics.

## 2. Improving Symptom-Based Medical Diagnosis Using Ensemble Learning Approaches

**Research source:** https://onlinelibrary.wiley.com/doi/full/10.1002/sres.3139

**Summary:**
This research investigates machine learning algorithms such as Decision Trees, Support Vector Machines and Logistic Regression, along with ensemble methods like Bagging and Stacking.

**What I learned:**
- Different algorithms can produce different prediction results.
- Ensemble learning can improve classification performance.
- Comparing multiple models helps select a suitable algorithm.

## 3. SymptomChecker – GitHub Project

**Research source:** https://github.com/Nurek54/SymptomChecker

**Summary:**
This GitHub project demonstrates a symptom-based disease prediction system using disease and symptom datasets. It includes data cleaning, dataset preparation, and model-related components.

**What I learned:**
- A structured dataset is important for disease prediction.
- Data cleaning and preprocessing are essential.
- Dataset quality and proper evaluation affect model reliability.

## Research Conclusion

After reviewing these research papers and projects, I understood how machine learning can be used for symptom-based disease prediction.

For the HealthBridge project, I plan to explore Random Forest and other classification algorithms using Scikit-learn.

The system will include a FastAPI backend, Streamlit interface, and SHAP explainability.

The system will be an educational decision-support prototype and not a replacement for professional medical diagnosis.
