# HealthBridge – Research and Repository Review

## 1. Scikit-learn
Repository: https://github.com/scikit-learn/scikit-learn

Scikit-learn is a Python machine learning library used for classification, regression, preprocessing and model evaluation.

**Application in HealthBridge:** It will be used to develop the disease prediction model using symptom data.

## 2. FastAPI
Repository: https://github.com/fastapi/fastapi

FastAPI is a Python framework used to develop APIs. It supports request validation and automatic API documentation.

**Application in HealthBridge:** It will connect the trained disease prediction model with the application and process symptom inputs.

## 3. SHAP
Repository: https://github.com/shap/shap

SHAP is a machine learning explainability library that helps explain how different input features influence model predictions.

**Application in HealthBridge:** It will help explain which symptoms contribute to a particular disease prediction.

## Proposed Architecture

1. Dataset collection
2. Data cleaning and preprocessing
3. Machine learning model training
4. Model evaluation
5. FastAPI backend integration
6. Streamlit user interface
7. SHAP explainability

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

## Conclusion

These three repositories provide the foundation for building the HealthBridge disease prediction and symptom checker application.
