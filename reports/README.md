# HealthBridge Hospitals – Disease Prediction and Symptom Checker

## Project Overview
HealthBridge is a machine learning project designed to predict possible diseases based on symptoms provided by users.

## Objectives
- Develop a disease prediction system.
- Support at least 25 disease categories.
- Build a FastAPI backend.
- Create a Streamlit user interface.
- Provide prediction explanations using SHAP.

## Technology Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- Streamlit
- SHAP

## Project Architecture
1. Data collection
2. Data preprocessing
3. Model training
4. Model evaluation
5. API development
6. User interface development
7. Explainable AI

## Evaluation Metrics
Accuracy, Precision, Recall and F1-score.

## Installation Instructions

1. Install Python.
2. Clone the GitHub repository.
3. Create a virtual environment.
4. Install dependencies using:

`pip install -r requirements.txt`

5. Run the data pipeline:

`python src/data_pipeline.py`

## Dataset
The project uses the provided healthcare symptom-disease dataset.

## Project Status
Development and experimentation are carried out in stages. Model performance will be documented after evaluation.
